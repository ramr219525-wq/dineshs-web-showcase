# Dinesh Portfolio Builder

Prompt for Lovable:

Build a modern, single-page personal portfolio website for Dinesh, a B.Tech student. Use a clean, stylish, professional design with smooth scroll navigation between sections, a cohesive color palette (e.g., dark navy/teal with an accent color, or a modern gradient theme), good typography hierarchy, subtle animations/hover effects, and full responsiveness for mobile and desktop.

Header / Navbar:

Logo or name "Dinesh" on the left, nav links (About, Projects, Contact) on the right, sticky on scroll.
Include a short "About" tag: Dinesh, B.Tech student, 18 years old.

Hero Section:

Large heading introducing Dinesh, a tagline like "B.Tech Student | Aspiring Web Developer", a short intro paragraph, and a call-to-action button ("View Projects" or "Contact Me").

About Section (Body):

A styled card or split-layout section with a profile photo placeholder, bio text, education details (B.Tech, age 18), skills list with icons or progress bars/badges, and maybe a downloadable resume button.

Projects Section:

Grid or card layout showcasing two projects:
E-Commerce Website — brief description, tech stack used, image/screenshot placeholder, live demo/GitHub links.
EdTech Platform — brief description, tech stack used, image/screenshot placeholder, live demo/GitHub links.
Use hover animations on project cards.

Contact Section:

A styled contact form (name, email, message) plus direct contact info: phone number 1234567890, and a "Send Message" button.

Footer:

Social media icon links (LinkedIn, GitHub, Instagram, Twitter — as placeholder icons), email: kmt123@gmail.com, and a copyright line.

Make the overall design visually appealing with consistent spacing, modern fonts (like Inter or Poppins), and subtle scroll-reveal animations for each section.
